Ospedali e Unità Operative

Unità organizzativa ≠ reparto di degenza

Focus UOC: una Unità Operativa Complessa (UOC) è una classificazione amministrativa; non è sinonimo di reparto. Le UOSD e le unità funzionali private sono censite a parte. Dove la denominazione ufficiale non è stata confermata, compare una riserva.

Come pubblicarlo e aggiornarlo

Il pacchetto include questa pagina, un registro JSON separato, uno script di aggregazione RSS e un workflow GitHub Actions giornaliero. Una volta pubblicato su GitHub Pages, gli aggiornamenti vengono caricati direttamente nella pagina, senza dover sostituire l’HTML. Per attivarlo: carica i file in un repository, abilita Pages → Source → GitHub Actions, attiva Actions e i permessi di scrittura del workflow. Il monitor non invia candidature né comunica con gli ospedali.

Per un monitoraggio completo occorrono anche controlli umani dei portali senza RSS: il feed generato intercetta notizie e pubblicazioni indicizzate, ma non garantisce la rilevazione di ogni bando.
