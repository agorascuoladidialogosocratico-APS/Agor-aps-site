Prima configurazione: nell'editor Pages CMS fai «Sign in with GitHub», autorizza il repository agorascuoladidialogosocratico-APS/Agor-aps-site e aprilo. La configurazione delle sezioni è già predisposta. Le modifiche salvate vanno su GitHub e Cloudflare le pubblica se l'integrazione Git è attiva. L'editor è un servizio esterno protetto dall'accesso GitHub: questa pagina mostra soltanto istruzioni e anteprima, non concede permessi di amministrazione.

Le immagini pubblicate nel repository sono accessibili a tutti. Prima di caricare fotografie delle attività, verifica i consensi e le autorizzazioni delle persone ritratte.
